# Icon

## Назначение

`Icon` — символ: одноцветный векторный рисунок из словаря темы. Символ — это значение, а не компонент: он задаёт, что
показать, а как — решает место использования. На символ ссылаются компоненты (например, `Image`) и будущие фрагменты
текста.

Устройство такое же, как у `Spacing` и `TypographyRole`: имена — в контракте, рисунки — в теме. Тема `default` содержит
служебные символы, без которых не работают компоненты дизайн-системы. Фирменный набор символов определяет продукт;
расширение шкалы продуктом — общий вопрос для всех foundation-сущностей.

У символа нет цвета и размера:

- цвет задаёт место использования ролью `ColorRole`; рисунок служит маской, его собственная заливка не используется;
- размер — собственный размер рисунка (`width` и `height` SVG); раскладка компонента может вписать рисунок в другой
  размер с сохранением пропорций.

## Состав

| Файл                         | Роль                                                                |
|------------------------------|---------------------------------------------------------------------|
| `Icon.json`                  | Публичный контракт: служебные символы.                              |
| `definitions/IconScale.json` | Вспомогательное перечисление: имена символов.                       |
| `definitions/IconValue.json` | Тип величины в теме: файл SVG и отражение при письме справа налево. |
| `changelog.json`             | Журнал изменений API.                                               |
| `preview.json`               | Превью величины на странице документации Figma.                     |

Рисунки задаются в темах: по умолчанию — `themes/default/Icon.values.json` и файлы `themes/default/icons/*.svg`.
Рисунки темы `default` взяты из Material Symbols (Outlined, 24) под лицензией Apache 2.0
(`themes/default/icons/LICENSE.txt`).

## Варианты

Источником истины является `themes/default/Icon.values.json`.

| Вариант       | Смысл                                  | Отражение справа налево |
|---------------|----------------------------------------|-------------------------|
| `image`       | заглушка, пока изображение загружается | нет                     |
| `brokenImage` | изображение не загрузилось             | нет                     |
| `close`       | закрыть, очистить поле                 | нет                     |
| `check`       | отмечено, выполнено                    | нет                     |
| `chevronDown` | раскрыть список                        | нет                     |
| `arrowBack`   | вернуться на предыдущий экран          | да                      |

Ожидаемая модель на Kotlin:

```kotlin
sealed interface Icon {
    data object Image : Icon
    data object BrokenImage : Icon
    data object Close : Icon
    data object Check : Icon
    data object ChevronDown : Icon
    data object ArrowBack : Icon
}
```

Рисунок не входит в тип: генераторы строят ресурсы платформ из файлов темы.

| Платформа | Ресурс                                                                          |
|-----------|---------------------------------------------------------------------------------|
| Android   | VectorDrawable; `mirrored` — `android:autoMirrored="true"`                      |
| iOS       | Asset Catalog с SVG, `template` rendering; `mirrored` — направление «зеркально» |
| Figma     | компонент библиотеки `icon/<имя>` (`figma-mapping.md`, раздел 3.1)              |

## Рекомендации по использованию

- Используйте символ, когда смысл понятен без подписи: закрыть, назад, раскрыть. Если смысл неочевиден, добавьте текст
  рядом.
- Цвет символа берите из той же роли, что и у соседнего текста (например, `onSurface`), чтобы символ и текст
  читались вместе.
- Отражайте при письме справа налево только символы направления (стрелки, шевроны «вперёд» и «назад»). Предметные и
  симметричные символы (картинка, галочка, крестик) не отражаются.

Требования к рисунку в теме (проверяет валидатор):

- файл SVG существует по пути `source` относительно каталога темы;
- `viewBox` квадратный;
- один цвет: заливки и обводки либо не заданы, либо заданы одним цветом; градиенты не используются;
- без растровых вставок (`<image>`).

## Ограничения и открытые вопросы

1. Шкала содержит только служебные символы; новые добавляются вместе с компонентами, которым они нужны. Символы
   продукта — задача продуктовых шкал для всех foundation-сущностей.
2. Многоцветные рисунки символами не являются: для них предполагается отдельный ресурс (иллюстрация).
3. Оптически скорректированные рисунки для разных размеров (например, 16 и 24 с разной толщиной линии) — отдельные
   символы словаря, а не масштаб одного.
4. Генерация ресурсов платформ из SVG выполняется генераторами платформ; пока их нет.
