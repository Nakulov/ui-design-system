# Size

## Назначение

`Size` задаёт размеры компонентов и их частей: иконок, аватаров, высоты кнопок и полей ввода, областей нажатия.
Используется единая шкала для всех компонентов.

Сущность описывает только фиксированные размеры. Поведение по содержимому и по доступному пространству (hug и fill)
в контракт не входит: на платформах размер компонента задаёт вызывающий код (`Modifier` в Compose, `.frame` в
SwiftUI), а в Figma — настройки Auto Layout у instance. Поведение частей внутри компонента описывается проектом
Figma-компонента (`<Имя>.figma.json`).

Величины задаются в условных единицах: `dp` на Android, `pt` на iOS, `px` в Figma.

## Состав

| Файл              | Роль                                                      |
|-------------------|-----------------------------------------------------------|
| `Size.json`       | Публичный контракт: значения шкалы и произвольный размер. |
| `SizeScale.json`  | Вспомогательное перечисление: именованные значения шкалы. |
| `SizeCustom.json` | Вспомогательный объект: произвольный размер вне шкалы.    |

Величины шкалы задаются в темах: по умолчанию — `themes/default/Size.values.json`.

## Варианты

Величины справочные: источником истины является `themes/default/Size.values.json`.

| Вариант  | Величина по умолчанию |
|----------|-----------------------|
| `zero`   | 0                     |
| `xs2`    | 12                    |
| `xs`     | 16                    |
| `s`      | 24                    |
| `m`      | 32                    |
| `l`      | 40                    |
| `xl`     | 48                    |
| `xl2`    | 56                    |
| `xl3`    | 64                    |
| `custom` | произвольное целое    |

Ожидаемая модель на Kotlin:

```kotlin
sealed interface Size {
    data object Zero : Size
    data object Xs2 : Size
    data object Xs : Size
    data object S : Size
    data object M : Size
    data object L : Size
    data object Xl : Size
    data object Xl2 : Size
    data object Xl3 : Size
    data class Custom(val value: Int) : Size
}
```

Величины значений шкалы не входят в тип: они генерируются из темы и берутся из неё, например
`LocalSizeValues.current.of(Size.M)`. `Custom` несёт собственную величину.

## Рекомендации по использованию

- Используйте значения шкалы для размеров иконок, аватаров и высоты элементов управления: это сохраняет единые
  пропорции интерфейса.
- `custom` используйте только в исключительных случаях, когда ни одно значение шкалы не подходит.
- В Figma `custom` задаётся числом без привязки к переменной; как значение свойства Figma-компонента он недоступен.

## Ограничения и открытые вопросы

- Неотрицательность `custom.value` пока не выражается форматом контракта.
- Размеры не масштабируются вместе с системной настройкой размера шрифта.
