# BorderWidth

## Назначение

`BorderWidth` задаёт толщину обводок и разделителей: границ полей ввода, карточек, вторичных кнопок, линий между
элементами списка. Используется единая шкала для всех компонентов.

Сущность описывает только толщину. Цвет обводки задаётся ролями `ColorRole` (например, `outline`, `outlineStrong`).

Величины задаются в условных единицах: `dp` на Android, `pt` на iOS, `px` в Figma.

## Состав

| Файл                     | Роль                                                           |
|--------------------------|----------------------------------------------------------------|
| `BorderWidth.json`       | Публичный контракт: значения шкалы и произвольная толщина.     |
| `BorderWidthScale.json`  | Вспомогательное перечисление: именованные значения шкалы.      |
| `BorderWidthCustom.json` | Вспомогательный объект: произвольная толщина вне шкалы.        |

Величины шкалы задаются в темах: по умолчанию — `themes/default/BorderWidth.values.json`.

## Варианты

Величины справочные: источником истины является `themes/default/BorderWidth.values.json`.

| Вариант  | Величина по умолчанию |
|----------|-----------------------|
| `zero`   | 0                     |
| `s`      | 1                     |
| `m`      | 2                     |
| `l`      | 4                     |
| `custom` | произвольное целое    |

Ожидаемая модель на Kotlin:

```kotlin
sealed interface BorderWidth {
    data object Zero : BorderWidth
    data object S : BorderWidth
    data object M : BorderWidth
    data object L : BorderWidth
    data class Custom(val value: Int) : BorderWidth
}
```

Величины значений шкалы не входят в тип: они генерируются из темы и берутся из неё, например
`LocalBorderWidthValues.current.of(BorderWidth.S)`. `Custom` несёт собственную величину.

## Рекомендации по использованию

- `s` — обводка по умолчанию: поля ввода, карточки, разделители.
- `m` — выделение состояния: фокус, выбранный элемент.
- `l` — акцентные обводки и индикаторы, например активная вкладка.
- `zero` — явное отключение обводки, когда компонент поддерживает её по умолчанию.
- `custom` используйте только в исключительных случаях, когда ни одно значение шкалы не подходит.
- В Figma `custom` задаётся числом без привязки к переменной; как значение свойства Figma-компонента он недоступен.

## Ограничения и открытые вопросы

- Неотрицательность `custom.value` пока не выражается форматом контракта.
- Тонкие линии толщиной в долю единицы (например, 0.5 на iOS) не предусмотрены: величины целые.
