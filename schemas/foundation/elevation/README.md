# Elevation

## Назначение

`Elevation` задаёт уровень приподнятости элемента над поверхностью, который передаётся тенью: карточки, плавающие
кнопки, меню, диалоги. Компоненты используют только уровни; параметры тени задаются темой.

Тень состоит из одного слоя: смещение, размытие, цвет и необязательное растяжение. В тёмном режиме тень плотнее, чем в
светлом, чтобы оставаться заметной на тёмном фоне. Приподнятость в тёмном режиме дополнительно передаётся уровнями
поверхностей `ColorRole` (`surface1`–`surface3`).

Размеры задаются в условных единицах: `dp` на Android, `pt` на iOS, `px` в Figma.

## Состав

| Файл                  | Роль                                                      |
|-----------------------|-----------------------------------------------------------|
| `Elevation.json`      | Публичный контракт: уровни и произвольная тень.           |
| `ElevationScale.json` | Вспомогательное перечисление: именованные уровни.         |
| `ElevationStyle.json` | Вспомогательный объект: параметры тени уровня и `custom`. |

Параметры уровней задаются в темах: по умолчанию — `themes/default/Elevation.values.json`.

## Варианты

Параметры справочные: источником истины является `themes/default/Elevation.values.json`. Во всех уровнях
`offsetX` равен 0, растяжение не используется.

| Уровень | `offsetY` | `blur` | Цвет, `light`       | Цвет, `dark`        |
|---------|-----------|--------|---------------------|---------------------|
| `zero`  | 0         | 0      | `#00000000`         | `#00000000`         |
| `s`     | 1         | 3      | `#0000001F` (12 %)  | `#00000052` (32 %)  |
| `m`     | 2         | 8      | `#00000024` (14 %)  | `#0000005C` (36 %)  |
| `l`     | 4         | 16     | `#00000029` (16 %)  | `#00000066` (40 %)  |
| `xl`    | 8         | 24     | `#0000002E` (18 %)  | `#00000070` (44 %)  |

`custom` — произвольная тень с собственными параметрами `ElevationStyle`; в файл значений не входит.

Ожидаемая модель на Kotlin:

```kotlin
sealed interface Elevation {
    data object Zero : Elevation
    data object S : Elevation
    data object M : Elevation
    data object L : Elevation
    data object Xl : Elevation
    data class Custom(
        val offsetX: Float,
        val offsetY: Float,
        val blur: Float,
        val spread: Float = 0f,
        val color: Color,
    ) : Elevation
}
```

Параметры тени не входят в тип: они генерируются из темы и берутся из неё, например
`LocalElevationValues.current.of(Elevation.M)`. `Custom` несёт собственные параметры. На Android тень рисуется через `Modifier.dropShadow` (Compose 1.9+), на
iOS — через `.shadow(color:radius:x:y:)`; генераторы пересчитывают размытие в единицы платформы.

## Рекомендации по использованию

- `s` — карточки, `m` — плавающие и приподнятые элементы, `l` — меню и выпадающие списки, `xl` — диалоги и нижние
  листы.
- Элементы длинных прокручиваемых списков оставляйте без тени или используйте не выше `s`; для разделения применяйте
  обводку `outline` или уровни поверхностей `surface1`–`surface3`.
- Не анимируйте параметры тени: при смене уровня переключайте его без анимации или анимируйте прозрачность и положение
  элемента.
- На iOS применяйте тень к фоновой фигуре элемента, а не к контейнеру с содержимым: иначе тень рассчитывается по форме
  всего содержимого и отрисовка дорожает.
- Не превышайте размытие 24 в собственных темах и в `custom`: стоимость отрисовки растёт с радиусом размытия.
- `custom` используйте только в исключительных случаях, когда ни один уровень не подходит.
- В Figma `custom` задаётся эффектом без привязки к стилю; как значение свойства Figma-компонента он недоступен.

## Ограничения и открытые вопросы

- Тень из нескольких слоёв не поддерживается: в формате нет типа «массив». Добавление слоёв изменит `ElevationStyle`,
  но не уровни `Elevation`.
- Растяжение (`spread`) не поддерживается в SwiftUI.
- Ограничение размытия пока не выражается форматом и не проверяется.
- Значения темы `default` — нейтральные стартовые значения; их следует проверить на реальных компонентах и замерить
  производительность на слабых устройствах.
