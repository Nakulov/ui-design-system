# TypographyRole

## Назначение

`TypographyRole` задаёт семантические роли текста: заголовки, основной текст, подписи элементов управления. Компоненты
используют только роли; шрифт, размеры и вес задаются темой.

Роли организованы группами по убыванию размера: `display…`, `headline…`, `title…`, `body…`, `label…`, `caption`.

Размеры задаются в условных единицах текста: `sp` на Android, `pt` на iOS, `px` в Figma.

## Состав

| Файл                       | Роль                                                   |
|----------------------------|--------------------------------------------------------|
| `TypographyRole.json`      | Публичный контракт: роли текста.                       |
| `TypographyRoleScale.json` | Вспомогательное перечисление: именованные роли.        |
| `TypographyStyle.json`     | Вспомогательный объект: параметры стиля текста.        |

Параметры ролей задаются в темах: по умолчанию — `themes/default/TypographyRole.values.json`. Файлы шрифтов темы
описаны в `themes/default/FontFace.values.json` и лежат в `themes/default/fonts/`.

## Варианты

Параметры справочные: источником истины является `themes/default/TypographyRole.values.json`. В теме `default` все
роли используют шрифт Inter.

| Роль                   | Размер / интервал | Вес | Межбуквенный |
|------------------------|-------------------|-----|--------------|
| `displayLarge`         | 36 / 40           | 700 | —            |
| `displayMedium`        | 32 / 36           | 500 | —            |
| `displaySmall`         | 28 / 32           | 500 | —            |
| `headlineLarge`        | 28 / 32           | 500 | —            |
| `headlineMedium`       | 24 / 28           | 700 | —            |
| `headlineSmall`        | 18 / 24           | 700 | —            |
| `titleLarge`           | 16 / 20           | 700 | —            |
| `titleMedium`          | 14 / 18           | 700 | —            |
| `titleSmall`           | 12 / 16           | 700 | 0.2          |
| `bodyLarge`            | 16 / 24           | 400 | —            |
| `bodyMedium`           | 14 / 20           | 400 | —            |
| `bodyMediumEmphasized` | 14 / 20           | 500 | —            |
| `bodySmall`            | 12 / 16           | 400 | —            |
| `labelLarge`           | 16 / 20           | 500 | —            |
| `labelMedium`          | 14 / 18           | 500 | —            |
| `labelSmall`           | 12 / 16           | 500 | 0.2          |
| `caption`              | 10 / 14           | 500 | 0.2          |

Ожидаемая модель на Kotlin:

```kotlin
sealed interface TypographyRole {
    data object DisplayLarge : TypographyRole
    data object DisplayMedium : TypographyRole
    // … остальные роли по тому же образцу
}
```

Параметры стиля не входят в тип: они генерируются из темы и берутся из неё, например
`LocalTypographyRoleValues.current.of(TypographyRole.BodyMedium)`, где результат — платформенный стиль текста.

## Рекомендации по использованию

- Используйте роли, а не произвольные размеры шрифта.
- `label…` применяйте для текста элементов управления (кнопки, вкладки, чипы), `body…` — для содержимого.
- Продукт может задать в своей теме другие шрифты и дополнительные режимы, например для письменностей, которым нужны
  другие шрифт и межстрочный интервал.

## Ограничения и открытые вопросы

- Сопоставление ролей с системными стилями текста iOS для поддержки Dynamic Type не определено.
- Параметры, специфичные для платформ (например, `LineHeightStyle` в Compose), в контракт не входят и задаются
  генераторами.
