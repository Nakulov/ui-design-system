# CornerRadius

## Назначение

`CornerRadius` задаёт радиус скругления углов элементов: кнопок, карточек, полей ввода, изображений. Используется
единая шкала для всех компонентов.

Сущность описывает только величину радиуса. Какие углы скругляются (все, только верхние и т. д.), определяет компонент.

Величины задаются в условных единицах: `dp` на Android, `pt` на iOS, `px` в Figma.

## Состав

| Файл                       | Роль                                                       |
|----------------------------|------------------------------------------------------------|
| `CornerRadius.json`        | Публичный контракт: значения шкалы.                        |
| `CornerRadius.values.json` | Файл значений: величины шкалы в условных единицах.         |
| `CornerRadiusScale.json`   | Вспомогательное перечисление: именованные значения шкалы.  |

## Варианты

Величины справочные: источником истины является `CornerRadius.values.json`.

| Вариант | Величина по умолчанию |
|---------|-----------------------|
| `zero`  | 0                     |
| `xs`    | 4                     |
| `s`     | 8                     |
| `m`     | 12                    |
| `l`     | 16                    |
| `xl`    | 24                    |
| `full`  | 9999                  |

`full` означает полное скругление: радиус равен половине меньшей стороны элемента (форма «таблетка» или круг).
Величина 9999 заведомо превышает размеры элементов; Figma, Android и iOS ограничивают радиус половиной меньшей стороны.

Ожидаемая модель на Kotlin:

```kotlin
sealed interface CornerRadius {
    data object Zero : CornerRadius
    data object Xs : CornerRadius
    data object S : CornerRadius
    data object M : CornerRadius
    data object L : CornerRadius
    data object Xl : CornerRadius
    data object Full : CornerRadius
}
```

Величины не входят в тип: они генерируются из файла значений и берутся из темы, например
`LocalCornerRadiusValues.current.of(CornerRadius.M)`.

Контракт имеет тип `oneOf` с одним развёрнутым перечислением, чтобы произвольный радиус (`custom`) можно было добавить
новым элементом `oneOf` без несовместимых изменений.

## Рекомендации по использованию

- Выбирайте значение шкалы по размеру элемента: чем крупнее элемент, тем больше радиус.
- `full` используйте для элементов-«таблеток» (кнопки, чипы, бейджи) и круглых элементов (аватары).
- Не задавайте вложенному элементу радиус больше, чем у контейнера.

## Ограничения и открытые вопросы

- Ограничение радиуса половиной меньшей стороны для `full` требуется проверить в реализациях Android (Compose) и iOS
  (SwiftUI).
- Произвольный радиус вне шкалы (`custom`) пока не предусмотрен.
